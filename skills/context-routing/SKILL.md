# Context Routing

Read nodes with `context_graph_get`. Add reviewed edges with `context_graph_add_edge`; use `MANUAL` for user-created relationships. Do not guess unknown targets. Preserve `MANUAL`, `FORCE_INCLUDE`, and `FORCE_EXCLUDE` relationships.
